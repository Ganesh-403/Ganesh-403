### 🧠 Building agent-native intelligence & high-performance Go infrastructure.

I am an **AI Engineer @ Flid AI**, currently building **[LeapView](https://github.com/flidai/leapview)** — an open-source, agent-native BI platform powered by **Go** and **DuckDB**. I specialize in building scalable backend systems, governed semantic data layers, analytics-as-code engines, and autonomous AI agents.

- 🚀 **What I'm Building**: **[LeapView](https://github.com/flidai/leapview)** — Open-source agent-native BI allowing teams to define analytics as code and query through interactive dashboards and AI agents.
- ⚡ **Core Stack**: **Go (Golang)**, **DuckDB**, **Python**, **Distributed Systems**, and **Agent Architectures**.
- 🔬 **Research & Publications**: Published **2 research papers** on distributed honeypot architectures and machine learning-driven threat classification.
- 🛠️ **Open Source & Community**: Project Admin & Maintainer for **ECSoC'26** and active open-source contributor (**GSSoC'26**).
