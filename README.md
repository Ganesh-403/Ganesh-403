## What I'm building

At **Flid AI**, I'm building **[LeapView](https://github.com/flidai/leapview)**, an open-source BI platform for governed analytics. Teams define semantic models and dashboards as code, review changes in Git, and explore their data through dashboards and AI agents.

My focus spans **Go backends, DuckDB query execution, semantic data models, and agent systems**. I enjoy the engineering behind a useful interface: how data is modeled, how context is retrieved, and how a system stays reliable as it grows.

## Selected projects

### [LeapView](https://github.com/flidai/leapview) — Governed analytics as code

Semantic models and dashboards live alongside code in Git. A Go backend compiles the resource graph, enforces access policies, and executes analytical queries through DuckDB.

**Go · DuckDB · SQL · TypeScript**

### [RepoSage](https://github.com/Ganesh-403/Repo-Sage) — Ask questions about your codebase

Local LLM inference with code search and dependency context. Combines Python AST parsing, a call graph, and hybrid retrieval so answers can point back to source files and line numbers.

**Python · LangGraph · Ollama · ChromaDB · NetworkX · FastAPI**

### [HoneyCloud](https://github.com/Ganesh-403/honeycloud) — Observe attacks across six protocols

A honeypot platform for SSH, FTP, HTTP, Telnet, SMTP, and RDP. Captures attack events, builds attacker profiles, and streams live telemetry to a dashboard. The current backend uses Rust, Axum, and PostgreSQL.

**Rust · Axum · Tokio · PostgreSQL · WebSockets · Docker**

### [Semantic Plagiarism Detector](https://github.com/Ganesh-403/semantic-plagiarism-detector) — Compare meaning across documents

Finds semantically similar passages using multilingual sentence embeddings and vector search. A Streamlit interface supports document comparisons, similarity heatmaps, and paragraph-level inspection.

**Python · Sentence Transformers · FAISS · Streamlit** · [Try the demo](https://semantic-plagiarism-detector.streamlit.app/)
